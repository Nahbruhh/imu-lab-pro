# Experiment 001 — Cantilever Beam Vibration

This is the first Structural Vibration Lab experiment. It will compare
calibrated vibration measurements with beam theory and FEA modal predictions
before introducing state reconstruction or model updating.

Populate `experiment.yaml` only with measured or traceable engineering inputs.
Do not replace unknown geometry, material, boundary-condition, or sensor
values with assumptions.

## Planned evidence

- Specimen dimensions, mass, material source, and clamp definition
- Sensor identity, mounting, calibration, and acquisition-integrity record
- Repeated vibration captures under a documented excitation procedure
- Natural-frequency and damping estimates with method and uncertainty
- Euler–Bernoulli analytical prediction
- Independently prepared FEA modal prediction
- Measurement/theory/FEA comparison with explained discrepancies

The experiment is complete only when another person can reproduce the process
from the retained configuration, procedure, data, and report.
