# Data conventions

- Use SI units in stored project metadata and calculations.
- Preserve original raw values or an immutable raw capture.
- Store timestamps, sequence identifiers, sensor settings, and calibration ID.
- Record processing parameters with every derived result.
- Use explicit channel names and coordinate-frame identifiers.
- Do not overwrite raw data with filtered or calibrated values.

Published example data must be small, reviewed, and free of private machine or
operator information.
