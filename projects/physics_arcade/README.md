# Physics Arcade

Physics Arcade contains small interactive projects that use the measurement
and orientation capabilities of IMU LAB Pro for playful physical interfaces.

| ID | Game | Control |
|---|---|---|
| 001 | [Rafale Rush](games/001_rafale_rush/) | IMU pitch and forward-thrust boost |

These games are demonstrations, not validated flight or vehicle simulations.
Reusable acquisition and orientation code remains under `src/imu_lab_pro/`.
